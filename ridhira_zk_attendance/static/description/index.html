Quick Start & Setup Guide

Method 1: Cloud ADMS Push Setup (Recommended for Cloud / Odoo.sh / Remote Branches)

  1. Navigate to Attendances ‣ Biometric Devices ‣ Terminals Dashboard.
  2. Click New and enter a Device Name.
  3. Set Protocol Mode to Cloud ADMS Push Server (ICLK).
  4. Enter the Serial Number (SN) of your ZK device.
  5. On the physical biometric machine menu, go to Comm. ‣ Cloud Server / ADMS / Web Server:
    • Server Address: Enter your Odoo server domain or IP (e.g., your-odoo-domain.com).
    • Server Port: Your Odoo web port (80, 443, or 8069).
    • Enable Domain Name: Yes (if using domain name) or No (if direct IP).
  6. Reboot the device. The status will turn to Online, and punches will push into Odoo instantly!

Method 2: Direct Network Polling (For Local On-Premise LAN)

  1. Install the Python ZK library on your Odoo server:
    pip install pyzk
  2. Go to Attendances ‣ Biometric Devices ‣ Terminals Dashboard.
  3. Create a device with Protocol Mode: Direct TCP/IP Polling.
  4. Enter the Device IP (e.g. 192.168.1.201) and Port (4370).
  5. Click Test Connection. The system will retrieve device model, serial number, and firmware.
  6. Click Download Punches to perform your first sync. The automated background cron will handle periodic downloads every 15 minutes!

Method 3: Universal REST API Webhook

Post JSON punch logs to: http://your-odoo-domain.com/api/biometric/punch
